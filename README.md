# SPD Research Tool – עברית, מראה Windows 11, EXE יחיד (שימוש פנימי)

## מה זה עושה
- **תרגום לעברית** של כל מחרוזות הממשק (תפריטים, דיאלוגים, הודעות, הודעות שגיאה) – `translations/he_glossary.py`.
  גיאומטריה, סגנונות ומיקומי הכפתורים **אינם משתנים** (מוחלף טקסט בלבד, נבדק ב-round-trip בית-אחר-בית).
- **מראה Windows 11 (קוסמטי)**: Common Controls v6, DPI מודע, Segoe UI בדיאלוגים.
- **דרייברים מוטמעים**: בהרצה הראשונה מותקנים בשקט (בקשת UAC אחת), אחר כך לא צריך להתקין כלום.
- **קובץ EXE אחד**: `SPD_Research_Tool_HE.exe` (נבנה ב-GitHub Actions).

## בנייה
דחיפה ל-`main` או Run workflow ידני -> Artifact בשם `SPD_Research_Tool_HE`. תג `v*` יוצר Release.

## כוונון
- `DIALOG_FONT` ב-`build.yml`: `9,Segoe UI` (ברירת מחדל). אם חלון נראה גדול מדי: `8,Segoe UI`. ריק = פונט מקורי.
- תרגום: עורכים `translations/he_glossary.py` (מפתח = טקסט המקור המנורמל) ודוחפים.
- `VERSION`: להעלות כדי שהמשתמשים יקבלו חילוץ מחדש.

## הערות
- הכלי עושה פלאש למכשירים; בדוק על מכשיר לפני שימוש בשטח.
- מחרוזות שהקוד כנראה מסתמך עליהן (שם האפליקציה, רשימת ה-baudrate, כותרות CSV) לא תורגמו בכוונה.
- ההודעות שמוטמעות בתוך קוד ה-DLL (לא במשאבים), כגון שורות הלוג, אינן ניתנות לתרגום בלי בינארי-פאץ' ולכן נשארו באנגלית.
- ייתכן ש-Windows Defender יסמן אריזה כזו; הוסף חריגה לשימוש פנימי.
